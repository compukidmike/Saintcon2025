# Saintcon 2025 Badge

This year's badge is a comically oversized wrench. In technical terms it's a 50mm (~2in) wrench and the lanyard hole is a 10mm, naturally. It has an NFC tag embedded in the business end which is used for interacting with the badge game hardware. This, of course, involved turning Nuts which were NFC devices that would write one-time codes to the NFC tag in the badge. The badge would then check those codes in with the game server which would either award points or unlock game nodes.

The board files and firmware for the badges and the nuts is included here. If you have any questions or want more info about anything, please let me know!
